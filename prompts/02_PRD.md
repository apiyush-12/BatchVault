# Prompt 02 — Create PRD

Read only:

- `/docs/project-context.md`

Your only job in this step is to create:

`/docs/PRD.md`

Do not write application code.
Do not create database migrations.
Do not install dependencies.
Do not create any other documentation file.

## PRD requirements

Write a practical Product Requirements Document for BatchVault.

Include:

1. Product overview
2. Problem statement
3. Product goals
4. Non-goals
5. Primary user types
6. User personas
7. Core jobs-to-be-done
8. Main user journeys
9. Functional requirements
10. Non-functional requirements
11. Batch privacy model
12. Roles
13. Permission expectations
14. MVP scope
15. Post-MVP features
16. Edge cases
17. Abuse / moderation considerations
18. Data portability expectations
19. Accessibility expectations
20. Performance expectations
21. Success metrics
22. MVP acceptance criteria

## Required roles

At minimum consider:

- Batch Owner
- Batch Admin
- Moderator
- Member
- Optional Guest / Public Viewer for explicitly public content

Do not assume every batch is public.

## Required MVP capabilities

At minimum evaluate:

- signup/login
- profile onboarding
- create batch
- batch identity
- batch privacy
- invite classmates
- join batch
- membership approval where needed
- upload photos
- upload short videos
- captions
- event/date metadata
- batch gallery
- memory detail page
- comments
- reactions
- basic member management
- reporting/removal
- batch settings

## Important constraints

Do not add:
- direct messaging
- public follower system
- reels feed
- dating
- marketplace
- cryptocurrency
- blockchain
- facial recognition
- live streaming

These are outside the MVP.

When complete:

1. summarize the MVP in 10 lines or fewer,
2. list any unresolved product decisions,
3. then STOP.

Do not start architecture in this step.
